# Changelog
All notable changes to this package will be documented in this file.

## [0.1.0] - 2025-09-06

### Added
- 重构框架 优化自有播控和PICO播控内容


## [0.0.8] - 2025-05-19

### Added
- 添加transformEffect distance开关
- 添加partcle shader uv
###Changed
- 优化客户端多人同步

## [0.0.7] - 2025-05-12

### Added
- 添加区域切换功能
- 添加shader效果
- 添加鉴权逻辑
- 添加HDR
###Changed
- 优化客户端断线重连
- 优化同步组件
### Fixed
- 修复手势操作转场失效

## [0.0.6] - 2025-04-08

### Added
- 添加timeline断线重连逻辑
- 添加客户端离线运行逻辑
- 添加pbr shader 增加溶解
- 添加墙体高度设置
- 添加同步类型选项
- 添加玩家昵称显示
- 添加昵称朝向组件

## [0.0.5] - 2025-04-02

### Added
- 添加睁眼效果
- 添加脚印开关

- 添加粒子材质增加溶解效果
- 添加同组与非同组玩家加载
- 添加安全区域编辑及显示逻辑
- 添加指引线逻辑

## [0.0.4] - 2025-03-29

### Added
- 添加大空间开发组件
- 添加单例管理器
- 添加引导脚印
### Changed
- 优化光照贴图亮暗变化
- 优化shader

## [0.0.3] - 2025-03-20

### Added
- 添加大空间网络交互逻辑
- 添加UniTask
